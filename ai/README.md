# U-GAS AI Guidance

The `ai/` directory contains portable policies. Root `AGENTS.md` routes a task into only the relevant layer; policies do not replace target-repository rules or current repository state.

## Layers

1. `GOVERNANCE.md` — precedence, evidence, owner abstraction, complexity, boundaries, and completion.
2. `GITHUB_WORKFLOW.md` — clone identity, capability recovery, safe Git/GitHub sequence, and handoff.
3. `SESSION_CONTINUITY.md` — resume, active state, checkpoints, interruption, and successor sessions.
4. `LARGE_FILE_PATCHING.md` — complete-content and guarded targeted edits.
5. `MULTI_AGENT_COLLABORATION.md` — shared-surface, provenance, handoff, and semantic merge boundaries.
6. `REPOSITORY_STRUCTURE.md` — PICA and document responsibility semantics.
7. `COMPLIANCE.md` — portable read-only U-GAS distribution/self-check contract.
8. `handoffs/README.md` — optional repository-backed long-handoff transport and selection rule.

Use the matching skill for task-level procedure, then target-local adapters and current state. Do not duplicate the policies into every project, create fleet sync, or treat external instructions as authority.
