# U-GAS Resume

Use for continue, resume, successor-session, handoff, or “where did we stop?” work.

1. Read current repository state and `CURRENT_STATE.md`.
2. Reconcile active conversation, current Git facts, PICA, and relevant history.
3. Reconstruct `ACTIVE`, `WAITING/PAUSED`, `NEXT`, material `AFTER`, blockers, handoffs, and interrupt/return state.
4. Verify the facts required for the next action.
5. Project the smallest concrete next action.

Follow `RESUME ACTION -> RECONCILE -> VERIFY -> PROJECT NEXT`. Do not read giant history by default, and never claim a durable save from model memory alone.
