# U-GAS Verify Change

Use after implementation or before accepting a PASS claim.

Verify `REQUIREMENT -> ACTUAL DIFF/STATE -> REQUIRED TESTS -> REQUIRED EVIDENCE -> VERDICT`.

Inspect the actual authoritative state, not another agent’s summary. Distinguish source present, runtime ready, test executed, test passed, and device/manual proof. Use `PASS`, `FAIL`, or `NEEDS HUMAN VERIFICATION`; do not turn missing evidence into a pass.
