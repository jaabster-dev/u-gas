# U-GAS Project Starter

Use the [Starter](index.html) to describe a project, choose where it should live, and
copy one ready-to-use prompt into a coordinating AI chat. My computer is the only active,
owner-tested route in this public release. GitHub and My server / cloud remain visible but
disabled until dedicated end-to-end validation exists.

The Starter preserves the public U-GAS PICA, canonical source, identity/haiku marker,
exact attribution, durable resume artifact, capability escalation, and one-copy executor
return contracts. It does not claim independent validation or make Codex mandatory.
