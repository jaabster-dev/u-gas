What would U-GAS need access to later?

For a lasting project, an AI coding tool needs permission to work in a real folder. U-GAS's webpage cannot enforce the tool's access limits. Your computer may show a broader permission prompt than the project needs; you should decline if you are unsure. If your coding tool has a read-only or project-only permission mode, use that before granting broader access. We show the proposed changes before asking for setup.

Before you give any permission

See exactly what is proposed

No files are created by this page. Only the AI tool you choose can request project-folder access, and you can decline.

Location: a dedicated project folder, not your entire computer:

~/U-GAS Projects/project

Files that would be created if you approve:

  • AGENTS.md — how the AI should work
  • CURRENT_STATE.md — current work and the next action
  • PROGRESS.md — what has been completed
  • IDEAS.md — ideas for later
  • GIVE THIS TO YOUR NEXT AI CHAT.txt — a simple way to resume
  • .git/ — optional local private history; not a GitHub upload

The exact folder must be checked by the AI. It must not overwrite an existing project or create a public GitHub repository.

Existing project: Project location to be confirmed

First, the AI will ask permission to read only this project. Reading files can itself trigger macOS access prompts. After inspecting, it must list any proposed files or modifications and request separate permission before writing. It must not silently migrate or overwrite your work.

What happens next?

  1. Review: the AI first explains its intended access and names the folder. A permission prompt is not proof of safety.
  2. Choose: allow only access you understand. Do not grant Full Disk Access or unexpected access to unrelated folders for this setup.
  3. Verify: the AI reports actual files and tests. If you refuse, it must stop local work and offer a read-only alternative without asking again.

Important: this webpage does not sandbox or control the AI application. Its permission requests are governed by that app and your operating system. GitHub sign-in is not needed for the local setup.
